Global Fuel Prices and Taxation Trends (2020–2026)
Project Overview
This project analyzes global fuel price trends across 84 countries and 7 regions from 2020 to 2026.
It explores petrol, diesel, and LPG prices to understand changes in fuel prices across countries and regions.
Dataset
Records: 27,468
Countries: 84
Regions: 7
Time Period: 2020–2026
Fuel Types: Petrol, Diesel, LPG
